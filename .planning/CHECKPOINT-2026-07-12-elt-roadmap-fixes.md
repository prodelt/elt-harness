## Fleet-v2 — модель пользователя (2026-07-12): Claude-оркестратор + провайдер-тьеринг гейта

Это **уточнение** существующего fleet (002/003), не переписывание. Дельта дизайна:

1. **Оркестратор = Claude, всегда** (не peer-воркер). Он раздаёт слайсы/задачи воркерам. Оркестрация = 0 LLM-токенов (код `tools/fleet/fleet.js`), но решение о маршрутизации — за Claude/классификатором.
2. **Роутинг по СЛОЖНОСТИ → тьер провайдера** (сейчас роутер по size-tag `[S/M/L]` — расширить до «сложность»):
   - **agy (Antigravity/Gemini)** — самый дешёвый и быстрый → тривиальные/`[P]`/бойлерплейт слайсы. НО «часто ошибается».
   - **codex** — середина.
   - **claude/opus** — трудное/архитектурное/диагностика.
   - Дефолт — механическая эвристика по тегам; опц. дешёвый Claude-classify для неоднозначных слайсов (ponytail: не звать LLM, где хватает тега).
3. **Провайдер-тьеринг ГЕЙТА (ядро идеи):** оракул одинаков для всех (механика, не ослаблять). Но **дифф от agy получает БОЛЬШЕ проверок**, не меньше:
   - обязательный sonnet-судья (не haiku),
   - `--max-budget-usd` жёсткий потолок на agy-инвокацию (новый примитив 2.1.207),
   - более узкий self-heal retry-бюджет для agy,
   - опц. вторая проверка/`ultrareview` на agy-диффах.
   - Гейт НИКОГДА не слабее baseline; agy просто получает СТРОЖЕ. «Дёшево и быстро» оплачивается «дороже на контроле качества».
4. **`--max-budget-usd` per-провайдер** в `.harness/fleet/fleet.json` — потолок расхода на воркера.

## Примитивы Claude Code 2.1.207 → рычаги (первичный источник: `claude --help` живьём)

Использовать нативное, НЕ изобретать (ponytail):

| Примитив | Рычаг для системы | Действие |
|---|---|---|
| **`--json-schema <schema>`** | вердикт судьи = валидируемый JSON, не парс прозы (был баг fleet #3) | Проверить, что fleet-судья уже отдаёт schema-validated verdict end-to-end; если нет — довести |
| **`--max-budget-usd <amount>`** | жёсткий $-потолок на инвокацию — контроль дешёвого agy | Ввести per-провайдер в fleet.json (Fleet-v2 п.3-4) |
| **`claude agents` + `--bg/--background`** | нативные managed фоновые агенты — субстрат Claude-оркестратора | Спайк: заменить ими PowerShell-джагглинг сессий воркеров |
| **`--worktree [name]` + `--tmux`** | нативный git-worktree на сессию | Оценить замену рукописного `tools/fleet/worktree.js` (удаление кода) |
| **`--fallback-model a,b,c`** | нативный 429-failover (до 3 моделей) | Упростить router-failover в fleet |
| **`--agents <json>` / `--append-system-prompt[-file]`** | инъекция судьи/харнесс-дисциплины в определение воркера | Инъектировать harness-промпт в agy-воркеров явно |
| **`ultrareview` (субкоманда)** | cloud multi-agent ревью ветки/PR | Опц. тяжёлая гейт-ступень на agy-диффах |
| **`--permission-mode plan\|dontAsk`** | новые режимы прав | Учесть в headless-воркерах |
| **`--include-hook-events` (stream-json)** | hook-lifecycle в выходном потоке | Наблюдаемость драйвера/fleet |
| **`--exclude-dynamic-system-prompt-sections`** | cross-run prompt-cache reuse | Экономия токенов на однотипных fleet-инвокациях |
| **`--session-id`/`-r`/`-c`/`--fork-session`** | пин/возобновление/форк сессии | Ротация (T007 `elt-drive.ps1` уже на них) |
