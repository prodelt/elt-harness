# 016 T006 — задача планировщика ожила

Дата: 2026-08-12.

## Было

```
TaskName       : \ELT-retro-label
Logon Mode     : Interactive only
Last Result    : 2147946720   ← 0x80070520 ERROR_NO_SUCH_LOGON_SESSION
```

Причина: `schtasks /Create` без `/RU`+`/RP` регистрирует задачу как «Interactive only». В 03:00
при заблокированной сессии интерактивного логона нет — задача не стартует вовсе, и ретро-разметка
молча не идёт (с 09.08 по 12.08 — ни одного прогона).

## Стало

```
LastRunTime    : 12.08.2026 9:36:36
LastTaskResult : 0
```

Регистрация переехала на `Register-ScheduledTask` (`schtasks` не умеет S4U вообще). Порядок
попыток в `installSchedule`:

1. **S4U** — «run whether user is logged on or not» без сохранённого пароля. Полное решение, но
   требует прав администратора: на обычном пользователе вернуло `0x80070005` PermissionDenied.
2. **Interactive + `-StartWhenAvailable`** — сработавший fallback. Несущая часть здесь именно
   `StartWhenAvailable`: пропущенный в 03:00 запуск выполняется при первом появлении сессии.
   Для суточной накопительной разметки «в 03:00 либо при первом входе после» эквивалентно по
   смыслу, и 0x80070520 больше не возникает по построению.

Деградация не молчаливая: `installSchedule` возвращает `logonType`, а CLI печатает предупреждение
с командой для повторной регистрации из PowerShell «от имени администратора».

## Второй пруф: задача реально отработала, а не просто не упала

`LastTaskResult=0` говорит только, что процесс не свалился. Содержательный пруф —
`.harness/judge-bench/retro-report.json`, переписанный тем же прогоном:

```
ts: 2026-08-12T06:36:26.759Z   ← совпадает с LastRunTime 9:36:36 (UTC+3)
total: 216 вердиктов            ← накануне было 212
unknown: 21 (9,7%)
benchAdded: 0, benchTotal: 36
```

## Расхождение с буквой приёмки

Приёмка T006 требует «у `.harness/learnings.jsonl` з'являється новий запис із датою прогону».
Этот файл пишет `tools/elt-harness-propose.js` (эволюция гейта), а суточный проход
`elt-retro-label --daily` пишет `retro-report.json` — путь, названный в приёмке, к
`learnings.jsonl` не ведёт вовсе. Формулировка приёмки ошибочна; фактическим доказательством
прогона служит связка `LastTaskResult=0` + свежий `retro-report.json` со сдвинувшимся `total`.
`benchAdded: 0` при этом ожидаемо — см. `.planning/016-T007-bench-ingest-finding.md`.
