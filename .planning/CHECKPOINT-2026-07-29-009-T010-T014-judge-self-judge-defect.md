## ЕДИНСТВЕННЫЙ ОТКРЫТЫЙ ДЕФЕКТ — `fleet.js:177-189` `judgeAwayFrom`
```js
const p = JUDGE_ALTS.find((x) => x !== workerProvider && providerAvailable(x));
if (!p) { emit(cwd, {event:'judge-same-as-worker', ...}); return judge; }  // ← судья == воркер
```
При отсутствии доступной альтернативы возвращается судья, СОВПАДАЮЩИЙ с воркером слайса —
то есть слайс заверяет сам себя. Инвариант T010 («судья не может совпасть с провайдером своего
воркера ни первичным, ни verify») нарушен ровно в той ветке, где это опаснее всего.
Verify-судья (codex) это поймал и заблокировал — по делу. Теста на эту ветку нет.

**Развилка (решает юзер, есть цена):** безопасный исход = `judge-unavailable` → парковка слайса,
а не продолжение тем же провайдером. Цена: на машине с ЕДИНСТВЕННЫМ установленным CLI гейт
станет непроходимым в принципе (сейчас он проходит ценой самозаверения). Тот же `verifyAwayFrom`
проверить на ту же ветку.
