# elt-work — офисные скилы: ресёрч и шортлист (2026-07-01)

Цель: нетехнарь закрывает любую повседневную офисную задачу (Word/Excel/PowerPoint/PDF/документы)
через `/elt-work`. Принцип: **ставить готовое, не писать**.

## Установлено (официальные Anthropic — `anthropics/skills`, 157k★, backbone)
| Скилл | Задача |
|---|---|
| `docx` | Word: создать/читать/править .docx (отчёты, письма, шаблоны, TOC, таблицы, tracked changes) |
| `xlsx` | Excel: таблицы, расчёты, своды, формулы |
| `pptx` | PowerPoint: презентации/слайды |
| `pdf` | PDF: создание, извлечение, заполнение форм |
| `doc-coauthoring` | структурированное со-авторство документации |
| `internal-comms` | внутренние коммуникации/анонсы/рассылки |

Почему официальные: поддерживаются Anthropic, идут с рабочими скриптами (pandoc/docx-js/python),
лицензия ясная, не надо сопровождать самим.

## Уже есть (бизнес-скилы юзера — маршруты elt-work)

`itstep-lesson-builder` (образование), `obsidian-vault` (база знаний).

## Зависимости для реального исполнения — ПРОВЕРЕНО 2026-07-01
- `pandoc 3.9` ✓, `node v24` ✓, системный `Python 3.11` (через `py -3`) ✓.
- Поставлены `openpyxl` + `python-docx` в системный Python311 (`py -3 -m pip`).
- **Proof:** сгенерены `.planning/office-demo/report.xlsx` (5KB) + `report.docx` (36KB) с реальным контентом. Office-пайплайн РАБОТАЕТ.
- ⚠ **DEMO-ГОТЧА:** ambient `python` на PATH = **Hermes-venv** (`hermes-agent\venv`) без pip/libs. Office-скилы зовут `python` → упадут. На демо/раскатке: использовать `py -3` ИЛИ переставить PATH так, чтобы Python311 был перед Hermes-venv. `libreoffice`/`soffice` отсутствуют (нужны только для части конвертаций pptx/pdf — доставить при необходимости).
