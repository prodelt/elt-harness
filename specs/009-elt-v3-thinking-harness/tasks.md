## Фаза C — watchdog

- [X] **T007** `[P]` `tools/harness-watch.js` — детекторы поверх run-log/ledger/health: `limit-streak` (≥2 limitHit одного провайдера за окно), `red-repeat` (≥2 red-stop по одной задаче), `judge-dead-streak` (≥2 подряд), `oracle-slow` (время оракула выше медианы ×3), `stale-park` (парковка старше N часов), `circuit-off` (в проекте с кодом контур выключен). Режимы `--once` (разовый прогон, exit 0/1) и `--watch` (поллинг файла). Пишет `.harness/health.jsonl` (по записи на инцидент, идемпотентно по ключу). Тесты на каждый детектор поверх синтетического run-log. [files: tools/harness-watch.js, tools/harness-watch.test.js]

- [X] **T008** Авто-фиксы из закрытого списка + проводка: `limit-streak` → провайдер в cooldown (`router.cool`) и следующий вызов идёт по цепочке; `red-repeat` → задача паркуется без третьей попытки; `judge-dead-streak` → судья откатывается на фолбэк-провайдера на остаток прогона; всё прочее — только запись. Каждое действие пишет `{action, reason, from, to}` в health.jsonl. Драйвер и fleet зовут watchdog между слайсами (`--once`) и уважают его решения В МЕРУ СВОЕЙ маршрутизации: у fleet есть цепочка провайдеров, поэтому `cooldown` применяется к воркеру (`router.cool`); у solo-драйвера имплементатор один (claude, цепочки нет), поэтому он применяет `cooldown` к провайдеру СУДЬИ и пишет явный `watchdog-cooldown-noop`, если решение неприменимо. Перевод имплементатора драйвера по цепочке — это T010 (failover воркера), не этот слайс. Подтверждать (`ack`) можно только фактически применённое действие. Никаких действий, трогающих код или git. Плюс недостающая проводка времени оракула: `elt oracle`/`commit` пишут в run-log `oracle.durationSec` (сейчас длительность измеряется и печатается, но НЕ сохраняется — детектор `oracle-slow` из T007 мёртв на живых данных). Тесты: каждое действие применяется ровно раз, неизвестный класс не даёт действия, зелёный `elt oracle` оставляет в run-log запись с `oracle.durationSec`. [files: tools/harness-watch.js, tools/elt-loop.ps1, tools/fleet/fleet.js, tools/harness-watch.test.js, tools/elt.js, ~/.claude/bin/elt.js]
