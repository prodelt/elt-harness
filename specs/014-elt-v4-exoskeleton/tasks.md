# 014 — ELT v4: экзоскелет. Задачи

Порядок фаз обязателен: A снимает налог (работает сразу и в одиночку), B выносит проверку с пути,
C наполняет фон, D замыкает петлю, E раскатывает наружу. Каждая фаза закрывается своим слайсом и
может быть остановлена без поломки предыдущих.

## Красная линия: dogfood с точкой переключения

Спека реализуется **самим строящимся контуром**, а не старым. Точка переключения жёсткая:

| Слайсы | Каким контуром закрываются |
|---|---|
| T001–T005 | старый синхронный гейт 011 (нового ещё нет) |
| **после T006** | `.harness/harness.json` этого репо переводится на `verify: "background"` — **это часть T006, а не отдельное решение** |
| T007–T021 | новым спекулятивным контуром: коммит возвращает управление, красное приходит в очередь |

Смысл: каждый следующий слайс — живой тест предыдущего. Сломался новый контур на реальном слайсе —
это **пруф дефекта и материал для следующего слайса**, а не повод откатиться к старому пути
(правило §3.1 брифа, подтверждено на 011). Откат к `verify: "sync"` допустим ровно в одном случае:
фон не отдаёт вердиктов вообще (T008 пишет `bg-silent` три раза подряд) — тогда парковка и запись
в чекпоинт, утром решает пользователь.

Начиная с T007 каждый закрытый слайс обязан оставить в чекпоинте одну строку: сколько секунд
занял возврат управления и пришёл ли фоновый вердикт. Это и есть боевой замер для T021.

**Исполнителю (Sonnet 5, автономный ночной прогон):** все развилки решены в `spec.md` — при
неоднозначности слайс **паркуется** (`elt park`), а не решается на месте. Один слайс = один коммит
через `elt commit --task Txxx --spec specs/014-elt-v4-exoskeleton`. Красные линии: не трогать
`tools/elt.js` вне перечисленных в `[files:]` мест; не добавлять зависимостей (в репо нет
`package.json`); не править `~/.claude/skills/**` без явного слайса фазы E.

## Осознанно НЕ включено (и почему)

- **Флот гипотез** (вариант 3 разбора) — только после T021: иначе цена гейта умножается на число
  веток раньше, чем измерена цена одного.
- **Авто-revert красного фона** — очередь и задача, но не откат: откат чужой работы без спроса
  опаснее красной строки в очереди.
- **AST-парсер триггера ослабления** — эвристика по строкам, парсер после живого промаха (решение 5).
- **Числовой риск-скор** — нечем калибровать, пока ретро-разметка не даст ≥ 100 однозначных меток.
- **Новые скиллы и MCP** — при ~80 установленных маржинальная польза около нуля, контекстный налог
  реален (`tools/hook-diet.js`, `tools/token-impact.js`). Усиление идёт через фон, а не через
  добавление инструментов.
