6. **Нет самодиагностики петли.** Регрессии харнесса (как баг судьи) ловятся только когда

## Объём (что делаем)

Адаптивная, само-наблюдаемая версия петли уровня «harness, не vibes»:

- **F-live** — liveness-инварианты: судья и имплементатор, которые не отработали
  (пустой вывод / timeout / spawn-fail), дают отдельный статус `*-dead` (ERROR-STOP),
  НЕ маскируются под `block`/`pass`.
- **F-effort** — `--effort` проброшен через всю цепочку invocation; драйвер стартует
  слайс на `high`, эскалирует на `max` при красном оракуле (self-heal), возвращается на
  `high` на следующем слайсе. Плюс интерактивный «stuck-detector» — nudge, когда N
  подряд красных.
- **F-rotate** — на 200k интерактивный гард сам МЕХАНИЧЕСКИ пишет чекпоинт (git +
  последний run-log + следующий открытый слайс + resume-указатель) и выдаёт готовый
  `/elt continue` промпт. Плюс авто-ротация сессий для автономной работы через драйвер
  (fresh `claude -p` per-единица — «new+elt» делается драйвером, не руками).
- **F-cg** — `codegraph`-liveness в `doctor` (MCP доступен + индекс свежий + watcher жив)
  и опциональный pre-slice гард (громкий fail вместо тихой деградации).
- **F-selfheal** — watchdog гоняет СОБСТВЕННЫЙ оракул харнесса; при падении механически
  заводит self-heal слайс и (opt-in) чинит через драйвер с судьёй. Человек-гейт по умолчанию.
- **F-hygiene** — свести всё в один наблюдаемый `doctor`, снять/пересогласовать
  Fleet-experimental метку с реальностью, подмести stale-claim/stale-audit.

## Критерии приёмки

- Каждый слайс: новый тест в `tools/*.test.js` (или расширение `doctor.test.js`) падает
  без правки и зеленеет с ней; общий оракул зелёный.
- `bin/elt.js` и `tools/elt.js` перестают дрейфовать (тест утверждает единый источник).
- Пустой/timeout вывод судьи → run-log `judge-dead`, драйвер стопается с явной причиной,
  НЕ коммитит и НЕ трактует как block «по существу».
- Драйвер строит argv с `--effort high` на импле и `--effort max` на self-heal
  (проверяется на построителе аргументов, без живого спавна).
- Гард на ≥200k продуцирует файл-чекпоинт с обязательными секциями (git, last-run,
  next-slice, resume-prompt) — проверяется на синтетическом транскрипте.
- `doctor` показывает codegraph-liveness и статус self-drive-инвариантов одной командой.

## Вне scope (осознанные потолки, не забыть в судейской рубрике)

- **Интерактивная zero-touch ротация НЕ нативна.** Хук не может выполнить `/new` или
  `/elt` и перезапустить REPL. F-rotate для интерактива = механический чекпоинт +
  готовый промпт (человек жмёт new+paste ИЛИ внешний драйвер подхватывает). Истинная
  автономная ротация — это путь драйвера (`claude -p` per-единица). Не обещать невозможное.
- **F-selfheal — НЕ автономный самопереписывающий демон.** Только: обнаружил регрессию →
  завёл слайс → починка через тот же судья-гейт, merge в main по умолчанию человеком.
  Сломанный харнесс, чинящий сам себя без гейта, копает глубже — запрещено.
- Не менять контракт `elt.js` exit-кодов (это инварианты — их зеркалят тесты, не проза).
- Не трогать оракул проекта как «механику» — судья не может простить красный оракул.
- Не добавлять новые рантайм-зависимости (stdlib/Node встроенное; PS5.1-совместимость).
- Не рефакторить fleet сверх того, что требует конкретный слайс.
