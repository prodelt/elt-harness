## АКТ 3 — «Гейт справді блокує» 🎯 головний момент (~90 c)

Це money-shot. Формат — не потребує БД, відтворюється завжди.

> Порада для сцени: `cargo fmt --check` — це 5-й із 8 сенсорів, тож коміт «думає» ~20–30 c до відмови.
> Щоб «червоне» з'явилось миттєво — спершу покажи standalone `cargo fmt --check` (той самий ред одразу),
> а потім `git commit` — щоб довести, що це не просто лінтер, а **зуб гейта, який зупиняє коміт**.

```bash
# ламаю форматування у справжньому файлі (зайві пробіли):
printf '\n\nfn   demo_break( ) ->  () {  }\n' >> crates/gateway/src/registry/mod.rs

git add -A
git commit -m "demo: intentionally broken formatting"
#  → husky доходить до `cargo fmt --check` і ВІДХИЛЯЄ. Коміт не створено.

# «Машина сказала ні. Виправляю саме те, на що вказали»:
git checkout -- crates/gateway/src/registry/mod.rs    # прибрати демо-поломку
git status                                             # чисто, коміту немає
```

> Ключова репліка: **«AI неможливо вмовити словами. Рахунок веде машина — і вона щойно не пустила недороблений код.»**

*(Якщо хочеш показати повний зелений прохід — прибери поломку через `cargo fmt` замість checkout і закоміть щось справжнє; але checkout безпечніший — нічого не залишає в історії.)*
