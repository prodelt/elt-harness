3 · Что НЕ трогать (работает — проверено)

  • Гейт-машинерия исправна. Live-fire в изоляции: block (нет вердикта) → log-verdict CLI → allow. retry-cap (3) работает. Дыра логирования закрыта CLI — записи доходят.
  • codegraph-привычка. Индекс есть и свежий во всех проектах. Это твой самый сильный, токеново-дешёвый рычаг — продолжай звать codegraph_context вместо Read.
  • Диспетчер elt-code. Когда вызван — роутит корректно. Проблема не в нём, а в том, что его не вызывают.
  • Раскол ключей ledger — by design, не баг. CLI и гейт оба резолвят hashed-projectKey, пишут/читают один и тот же каталог. Консистентно.

4 · Как пользоваться новым elt-code (v0.9.0)

elt-code — тонкий диспетчер, не «ещё один режим». Он смотрит на твой интент и роутит в готовый скилл, а на код-задачах ставит судью последним перед «done». 7 интентов:

#КогдаКуда роутит
1«продолжи роадмап», голый вызовResume Pointer последнего checkpoint → /pipeline
2новая фича / крупноеgrill → spec-kit → /pipeline → судья H1 против spec.md
3багфикс/pipeline (BUG) → diagnose
4e2e / QA в браузереqa + agent-browser
5аудит качества (без задачи)судья standalone + ponytail-audit + perf + arch
6security (blue)security-best-practices
7дизайн / UI / awwwards / моушнdesign-studio (DESIGN.md) → frontend-ui / remotion-motion

Полный конвейер код-интента: контекст → grill (закалка плана) → spec-kit (контракт) → /pipeline (tdd/sprint) → live-fire (реально исполнить фичу) → судья (H1/H2/H3) → closeout (commit+память+checkpoint).

Лайфхаки (то, что реально меняет результат)

  1. Заходи через дверь по умолчанию. Любую кодовую задачу начинай с /elt-code "что нужно", а не сразу руками. Голый /elt-code покажет меню с подставленным Resume Pointer — это бесплатная навигация по состоянию проекта.
  2. Судью — ВСЕГДА изолированным субагентом, никогда инлайн. Если ты выносишь вердикт в том же контексте, где писал код — это self-judge, и он невалиден. В Claude: Task → sonnet (opus для COMPLEX/прод/секьюрити). Судья не видит твоих рационализаций — в этом вся ценность.
  3. «pass» без единого «block» в истории — это сигнал тревоги, а не успеха. Если судья никогда не блокирует, ты либо не даёшь ему реальный дифф, либо это формальность. Здоровая доля block — признак, что гейт живой.
  4. Логируй вердикт только через CLI: node tools/pipeline-state.js log-verdict --root "<repo>" --json '...'. Ручная дозапись в ledger теряется под давлением контекста (это уже было).
  5. Крупное (COMPLEX) — режь на слайсы в свежем контексте. 6 МБ-сессия платит за себя почти квадратично (каждый turn перечитывает всю историю). /clear между слайсами; тяжёлое чтение — в haiku-субагента; рабочий контекст <~50% окна.
  6. Тяжёлый интент #2 — не пропускай grill. Один раунд «закалки» плана до кода дешевле, чем переписывать слайс после суда.
  7. Дизайн — через интент #7, не вручную. design-studio даёт арт-дирекшн + библиотеку 74 эталонов; точный клон сайта по URL — это другой скилл (reference-design-adaptation), не путать.
  8. codegraph перед Read. codegraph_context первым на любой вопрос «как это устроено» — структурная выжимка дешевле чтения файлов целиком.

5 · Топ-рекомендации (по убыванию рычага)

  1. Реши судьбу судьи: либо настоящий субагент, либо честно убери. Сейчас он создаёт иллюзию контроля, не давая контроля. Если судить инлайн — переименуй в «самопроверку» и не считай гейтом. Если хочешь реальный гейт — правило: вердикт только из Task-субагента, иначе не логируется.
  2. ✅ СДЕЛАНО. Зубы перенесены туда, где код. judge-gate + git-guard поставлены в Fasoli/Geocode/Itstep/Marketing через tools/install-harness-teeth.js --root "<repo>". Установщик идемпотентен — добавляй им любой новый проект одной строкой. Файлы в чужих репо размещены, но не закоммичены — реши сам, гитигнорить .claude/ или коммитить.
  3. Подними adoption с 15%. Самый дешёвый ход — рефлекс «кодовая задача = /elt-code первой строкой». Itstep (0/35) и Md-drive (0/6) — где система не существует на практике.
  4. Включи петлю insights. Экспортируй Claude Code Insights в ~/.claude/usage-data/report.html → /usage-audit начнёт сам диффить тренды. Без неё нет обратной связи — ты летишь по приборам, которых нет.
  5. Распространи spec-kit на активные кодовые проекты. 2–3 из 11 — мало; specify init идемпотентен, ставится за один заход на проект.
  6. Дроби монолитные сессии. 6 МБ — красный флаг. Привыкни к /clear на границе слайса; checkpoint несёт состояние.
